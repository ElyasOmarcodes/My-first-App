# د Keyflux د وړاندیز، اصلاح او زده کړې سیسټم (1.2.0)

دا سیسټم د Samsung Keyboard د SwiftKey/Fluency د تحلیل له مخې جوړ شوی دی.
لاندې جدول ښيي چې د سامسونګ هر اصل زموږ په کیبورډ کې څنګه پلی شوی.

| د سامسونګ اصل | په Keyflux کې |
|---|---|
| **TDM** (لنډمهاله ماډل) | کومه کلمه چې په یوه فیلډ کې ولیکل شي، په همغه فیلډ کې سمدستي وړاندیز کېږي. کله چې فیلډ بدل یا بند شي، دا ماډل پاکېږي. (`WordStore.sessionLearn`) |
| **DLM** یوازې وروستی متن زده کوي | یوه کلمه هغه وخت زده کېږي چې د دوو نورو کلمو تر لیکلو وروسته لا هم په متن کې وي. که پیغام ولېږل شي (اپ فیلډ خالي کړي)، د پیغام کلمې هم زده کېږي. هغه کلمې چې پاکې شوې وي نه زده کېږي. |
| کلمه **۲ ځله** ولیدل شي بیا وړاندیز کېږي | د زده کړې کچې (levels): یوه کلمه له دویم ځل لیدو وروسته وړاندیز کېږي. |
| تر **۴ کلمو** پورې n-gram | د خپلو کلمو ترتیبونه تر ۴ کلمو پورې زده کېږي. وړاندیز له اوږد ترتیب څخه لنډ ته ځي (back-off). د پیغام پیل جلا حالت لري. یو ترتیب هغه وخت وړاندیز کېږي چې لږ تر لږه ۲ ځله لیدل شوی وي. (`learnSequence`، `suggestNext`) |
| Context = له کرسر مخکې **۶۴ توري** | د کرسر په هر حرکت کې له کرسر مخکې ۶۴ توري لوستل کېږي. یوازې اوسنۍ جمله په پام کې نیول کېږي. |
| اصلاح یوازې په **Space، `. , ! ?`، Enter (نوې کرښه)** | همدا، د `، ؟ ۔ ؛` سره. هغه Enter چې لېږي یا لټون کوي (Send/Search) هېڅکله اصلاح نه کوي. |
| هدف باید د **ثابت قاموس** کلمه وي | هغه کلمه چې یوازې کاروونکي زده کړې ده، هېڅکله ستاسو کلمه په اتومات ډول نه بدلوي. |
| د تېروتنو حد | تر ټولو زیات ۱ اضافي توری، ۱ پاتې توری، ۱ ځای بدل شوي توري، او ۲ غلط توري. |
| بشپړول (completion) | یوازې هغه وخت چې ≥ ۴ توري لیکل شوي وي او کلمه ≥ ۶ توري ولري. |
| **۲× / ۱۰×** احتمال | هدف باید له دویم کاندید څخه ۲ ځله (کله چې تېروتنه سمېږي) یا ۱۰ ځله (په نورو حالتونو کې) ډېر احتمال ولري. |
| KPM (د لمس ماډل) | د تېروتنو وزن: نږدې کیلي، پاتې توری او ځای بدل شوي توري ارزانه دي. لرې کیلي او هغه توري چې د کلمې په پای کې پاتې وي ګران دي. (`replaceReading`) |
| KPM یوازې له سمو لمسونو زده کوي | د لمس ماډل یوازې هغه لمسونه زده کوي چې کلمه یې هماغسې ولیکل شوه او په قاموس کې ده، یا یې وړاندیز انتخاب شو. |
| **revokedlist** | کومه اصلاح چې تاسو بېرته واخیستله، بیا هېڅکله نه تکرارېږي. دا لیست په دایمي ډول ساتل کېږي. |
| د استثناوو لیست | عدد، `- _ # @`، ټول لوی توري، CamelCase، د جملې په منځ کې لوی توری (خاص نوم)، `x.y`، او `'s` اصلاح نه کېږي. |
| بند فیلډونه | زده کړه بنده ده په: password، incognito، ایمیل، URL، او `disableLearning`. اصلاح بنده ده په: password، ایمیل، URL، نوم، پته، او `disableAutoReplacement`. |
| د **حساسو عددونو** فلټر | هېڅ کلمه چې عدد ولري نه زده کېږي. |
| ړنګې شوې کلمې | هغه کلمه چې له وړاندیز څخه ړنګه شي، بندېږي او بیا نه زده کېږي. |

**د ډکشنرۍ پاکول:** د ویکیپیډیا په ډکشنرۍ کې عامې غلطې املاوې هم وې، لکه `teh`، `goverment`، `کتبا` او `حکوت`. دا غلطې کلمې لرې شوې (`tools/dict/typo_filter.py`). یوه کلمه هغه وخت لرې کېږي چې:

- یو توری یې ځای بدل کړی وي، یا یو توری یې له منځه پاتې وي، او
- همغه سمه کلمه ۱۰۰ ځله ډېره عامه وي، او
- غلطه کلمه پخپله ډېره کمه کارېدلې وي.

د کلمو پای ته لاس نه دی وړل شوی، ځکه په پښتو، دري او اردو کې د کلمې پای د صرف (inflection) ځای دی.
