
## دری / فارسی (fa-AF / fa)

```
• کیبورد بسیار سریع‌تر شد: پیشنهادها جداگانه ساخته می‌شوند، دکمه‌ها فوراً می‌نویسند و در متن‌های طولانی کندی و حرف جاافتاده نیست
• فرهنگ‌های بزرگ ویکی‌پدیا برای ۵ زبان (تا ۲۵۰ هزار واژه)
• هر زبان میان‌برهای خودش را دارد؛ میان‌برهای پیش‌فرض پشتو، دری، عربی، اردو و انگلیسی
• فاصله خالی میان کیبورد و دکمه‌های پایینی گوشی برطرف شد
• پیشنهاد متن کپی‌شده: هرگز، یک بار یا همیشه
```

## English (en-US)

```
• Much faster typing: suggestions are worked out separately, so every key writes at once, with no lag or dropped letters in long messages
• Large Wikipedia dictionaries for all 5 languages (up to 250,000 words)
• Shortcuts per language, with default lists for Pashto, Dari, Arabic, Urdu and English
• Fixed the empty gap between the keyboard and the phone's bottom buttons
• Copied-text suggestion: never, once or always
```
